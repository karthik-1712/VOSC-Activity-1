# VOSC Activity-1 – Tic‑Tac‑Toe

## What is this project?
A simple, **pure‑HTML/CSS/JavaScript** implementation of the classic Tic‑Tac‑Toe game. It runs entirely in the browser – no backend, no external libraries.

---

## Features
- Two‑player local play (Player **X** vs Player **O**)
- 3 × 3 board with click‑to‑place moves
- Turn indicator and status messages
- Automatic win detection with highlighted winning line
- Draw detection when the board is full
- "Restart Game" button to start over
- Dark, premium‑style UI with smooth hover effects and responsive layout for mobile

---

## Technologies Used
- **HTML5** – semantic structure
- **CSS3** – custom dark theme, animations, responsive grid
- **Vanilla JavaScript** – game logic, DOM manipulation

---

## Project Structure
```
├─ index.html   → page markup and element placeholders
├─ style.css    → visual design, dark theme, animations
├─ script.js    → game state, win/draw logic, UI updates
└─ README.md    → this document
```

---

## How to Run the Game
1. **Download / clone** the four files into a single folder.
2. Open **`index.html`** in any modern browser (Chrome, Edge, Firefox, Safari).
3. The game loads automatically – no server or build step required.

---

## How to Play
- Player **X** always starts. Click an empty cell to place your mark.
- Players alternate turns. The status bar shows whose turn it is.
- When three of the same marks line up horizontally, vertically, or diagonally, the game declares a winner and highlights the three cells.
- If all nine cells are filled without a winner, the game shows **"It's a Draw!"**.
- Click **Restart Game** to clear the board and start a fresh match.
